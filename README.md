# Telegram-bot-n8n
Telegram-бот предназначен для пользователей, прошедших обучение в образовательном проекте производственной компании.   Он автоматически отвечает на часто задаваемые вопросы, ищет информацию в встроенных инструкциях и сохраняет вопросы, на которые не найден ответ, для последующей обработки администраторами.
