# 🤖 Telegram-бот на n8n для технической поддержки пользователей

## 📌 Описание проекта
Telegram-бот предназначен для пользователей, прошедших обучение в образовательном проекте производственной компании.  
Он автоматически отвечает на часто задаваемые вопросы, ищет информацию в встроенных инструкциях и сохраняет вопросы, на которые не найден ответ, для последующей обработки администраторами.

Бот работает круглосуточно, интегрирован с базой данных PostgreSQL и использует векторное хранилище (pgvector) для поиска по документам.

## ⚙️ Основные возможности

- 🧠 Поиск ответов в базе инструкций и готовых ответов  
- 💬 Автоматическая обработка сообщений пользователей (текст и голос)  
- ❓ Сохранение неотвеченных вопросов в отдельную таблицу  
- 📲 Запоминание Telegram-ID, имени пользователя и телефона  
- 🕓 Работа в автоматическом режиме 24/7  
- 🧾 Возможность последующего анализа и дополнения базы знаний

## 🏗 Архитектура проекта
Workflow состоит из трёх основных модулей:
1. **Обработка входящих сообщений** — анализ, проверка наличия телефона, обработка голоса.  
2. **Формирование ответа** — взаимодействие с LLM, поиск по таблицам `qa` и `documents`.  
3. **Отправка ответа** — передача пользователю и сохранение данных в `Nonanswered_questions` при отсутствии результата.

## 🗄️ Структура базы данных

```sql
CREATE TABLE public.documents (
    id bigint PRIMARY KEY,
    text text,
    metadata jsonb,
    embedding vector(1536)
);

CREATE TABLE public.qa (
    "вопрос" text,
    "ответ" text
);

CREATE TABLE public.Nonanswered_questions (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp DEFAULT now(),
    question text,
    username text,
    telegram_id integer,
    phone_number text
);
```


### 🚀 Развёртывание

1. **Клонирование репозитория**

   ```bash
   git clone https://github.com/<your_username>/<your_repo_name>.git
   cd <your_repo_name>

2. **Настройка окружения**

Создайте файл `.env` на основе `.env.example` и заполните переменные:

    ```env
    POSTGRES_USER=
    POSTGRES_PASSWORD=
    POSTGRES_DB=
    TELEGRAM_TOKEN=
    YANDEX_API_KEY=

3. Запуск через Docker

    ```bash
    docker-compose up -d


После запуска:

- **n8n** доступен по адресу: [http://localhost:5678](http://localhost:5678)
- **PostgreSQL** — `localhost:5432`

Импортируйте файл [`workflow.json`](workflow.json) в n8n и активируйте сценарий.
